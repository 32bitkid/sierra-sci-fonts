# &ldquo;SciAC FONT.000 Free&rdquo; &amp; &ldquo;SciPX FONT.000 Free&rdquo;

This version of Sci FONT.000 can be built freely available demos and
promotional software released by Sierra On-Line. It will cover enough for
ASCII english text.

## Building

### Sources

This definition requires _three_ sources, to fully render. [ScummVM](https://www.scummvm.org/demos/) 
provides downloadable copies of many, if not all, these archived demo releases. You will need
_one_ of each source to build.

1. **Source_A**
   - Kings Quest 4 SCI Demo
   - Kings Quest 1 SCI Demo (1989 EGA Remake)
   - Conquests of Camelot Demo
   - Codename: ICEMAN Demo
   - Colonel's Bequest Demo
   - Leisure Suit Larry Goes Looking for Love (in Several Wrong Places) Demo
   - Leisure Suit Larry III: Passionate Patti in Pursuit of the Pulsating Pectorals Demo
   - Police Quest 2 Demo
   - Quest for Glory I Demo
   - Quest for Glory II Demo (with `"engine": "sci01"`) 
2. **Source_B**
   - Astro Chicken Demo
   - Space Quest 3 Demo
3. **Source_C**
   - Sierra Christmas Card 1988
