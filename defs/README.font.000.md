# &ldquo;SciAC FONT.000&rdquo; &amp; &ldquo;SciPX FONT.000&rdquo;

This version requires more sources, that can be difficult to find, but
will result in a font tha covers most of the Latin-1 Supplement block
allowing for easier usage for languages outside of `en-US`/`en-GB`.

## Building

### Sources

This font requires _seven_ sources to fully compile, some of them can be resolved with "free"/"demo"
content that is available, however most are retail releases, and some are _foreign_ retail releases. 
That makes some sources fairly difficult to track down. You will need _one_ of each source to compile 
all the glyphs.

1. `SCI_FONT_000_A`
   - Kings Quest 4 SCI Demo
   - Kings Quest 1 SCI Demo (1989 EGA Remake)
   - Conquests of Camelot Demo
   - Codename: ICEMAN Demo
   - Colonel's Bequest Demo
   - Leisure Suit Larry Goes Looking for Love (in Several Wrong Places) Demo
   - Leisure Suit Larry III: Passionate Patti in Pursuit of the Pulsating Pectorals Demo
   - Police Quest 2 Demo
   - Quest for Glory I Demo
   - Quest for Glory II Demo (with `"engine": "sci01"`)
   - _...most Sierra releases between 1988–1990 will work here._

2. `SCI_FONT_000_B`
   - Astro Chicken
   - Space Quest III Demo
   - Space Quest III: The Pirates of Pestulon (US)
   - Space Quest III: The Pirates of Pestulon (GERMAN)
   - Space Quest III: The Pirates of Pestulon (ITALIAN)

3. `SCI_FONT_000_C`
   - Leisure Suit Larry Goes Looking for Love (in Several Wrong Places) (US)

3. `SCI_FONT_000_D`
   - Leisure Suit Larry III: Passionate Patti in Pursuit of the Pulsating Pectorals (US)

4. `SCI_FONT_000_E`
   - Police Quest II: The Vengeance

5. `SCI_FONT_000_F`
   - Space Quest III: The Pirates of Pestulon (GERMAN)

6. `SCI_FONT_000_G`
   - Space Quest III: The Pirates of Pestulon (ITALIAN)

7. `SCI_FONT_000_H`
   - Leisure Suit Larry III: Passionate Patti in Pursuit of the Pulsating Pectorals (FRENCH)

7. `SCI_FONT_000_I`
   - King's Quest 4 SCI (US Retail)
