# Font Definitions

This folder contains the font definitions for use with [@4bitlabs/sciotf](https://github.com/32bitkid/sci.js/tree/main/apps/sciotf). This docment describes the different 
variations available in this folder.

## Variations


### `font.XXX.free.json`  Fonts

The `font.XXX.free.json`-named font definitions only reference glyphs that can be found in _free_ or _demo_ content
that was published by Sierra On-Line for open distrubtion. This includes interactive demos, non-interactive
demos, and other promotional content.

### `font.XXX.json`  Fonts

The `font.XXX.json`-named font definitions reference both free and commercial releases of Sierra On-Line
adventure games, but also include programatically generated fonts that were either never available,
or were stylistically different from the ASCII range font styles. These fonts attempt to fill these gaps and fix
glyphs to provide better over-all usability with modern workflows. 

If you are using these fonts in a modern web application or game, as either nostalgia or _hommage_, then these 
fonts are generally preferable.
